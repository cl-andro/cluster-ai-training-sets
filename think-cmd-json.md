# think-cmd-json.md — Thinking Model Dataset Expansion Plan

> **Current:** 10 batches, 1,000 entries across `terminal-training-set/`
> **Target:** Expand to 50+ batches, 5,000+ entries with `<think>` reasoning blocks

## Format

Each entry follows:
```json
{
  "instruction": "Realistic, multi-step or non-trivial DevOps/Linux system request",
  "output": "<think>\n1. Task Breakdown: ...\n2. Tool Selection & Logic: ...\n3. Safety & Edge Cases: ...\n</think>\n[Exact bash commands, script, or chained pipeline]"
}
```

## How It Works

Each entry's think block is generated by analyzing its instruction+output:
1. **Extract tools & commands** from the output (e.g., `systemctl`, `docker`, `kubectl`)
2. **Classify task type** (diagnostic, configuration, troubleshooting, automation)
3. **Generate contextual reasoning** with task breakdown, tool selection logic, and safety checks
